# Google Play Store Listing Draft

## App Name
AI Usage

## Short Description
Track your AI usage limits from your Android phone and widgets.

## Full Description
AI Usage keeps your AI service limits visible on Android.

Connect the Android app to AI Usage for Windows with Google sign-in, then view the active providers and remaining limits that your Windows app syncs to Firebase. The app focuses on a quick home dashboard, configurable connected devices, Android home screen widgets, and a pinned silent notification for status bar access.

Key features:
- View remaining limits for active AI providers such as Claude, Codex, Gemini, and GitHub Copilot.
- Sync latest snapshots from your signed-in Windows PC through Firebase.
- Show compact home screen widgets with provider icons and gauges.
- Keep a silent pinned notification with provider summaries and expandable gauges.
- Rename connected Windows devices to keep multiple PCs easy to identify.
- Korean UI is shown automatically when the device language is Korean.

AI Usage does not collect provider credentials, API keys, refresh tokens, local paths, raw logs, or authentication files. The mobile app displays sanitized usage snapshots uploaded by your signed-in Windows app.
